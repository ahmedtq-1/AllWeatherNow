AllWeatherNow is a tool that brings live weather to X-Plane 12 with more accurate, realistic data and effects.

1-extract all contents of zip file into FlyWithLua script folder and run the batch file, you can create a shortcut of the batch file to your desktop for easier access

2- For best results, start your flight with the live or current weather option unchecked and reload all FlyWithLua script and wait about two minutes for the live weather to fully load.

3- Avoid using other visual effects scripts, as they may conflict and/or reduce quality.

4- If it doesn’t work automatically, go to Plugins > FlyWithLua and reload all Lua scripts.

Python is required to run the bridge, if you don't have Python install it using command window then write (winget install -e --id Python.Python.3.14) for Windows, for Mac (brew update && brew install python and for Linux (curl -LsSf https://astral.sh/uv/install.sh | sh

uv python install 3.14).

Note: FlyWithLua NG+ (Next Generation Plus) must be installed beforehand for X-Plane 12: FlyWithLua NG+ (Next Generation Plus) Edition for X-Plane 12 (Win, Lin, Mac) - Utilities - X-Plane.Org Forum

Extra feature, if you want the macro OSD show the nearest airport to you can download airport csv file from Open data @ OurAirports and place it inside flywithlua script folder.

Enjoy flying with the ultimate weather simulation experience!
