# AllWeatherNow
AllWeatherNow is a tool that injects live weather to Xplane 12 with more accurate and real to life effects
Simply start the python script which bridge the live weather data to X-Plane 12 and place the Lua file in script folder of FlyWithLua
you are recommended to start the flight with live weather or current weath checkbox unchecked and wait for 2 minute for live weather to be generated.
